\# CodeNova Internship



Projects for the CodeNova Internship (Batch 01, Full Stack Development), built with Node.js, Express and SQLite.



| Task | Project | Folder |

|------|---------|--------|

| 1 | Notes Application: create, edit, search and delete notes | \[task-1-notes-app](task-1-notes-app) |

| 2 | Expense Tracker: income/expense tracking with validation and live balance totals | \[task-2-expense-tracker](task-2-expense-tracker) |



Each folder has its own README with setup steps, API documentation and screenshots.



\## Run any project



Requires Node.js 18+.



```bash

cd task-1-notes-app/server        # or task-2-expense-tracker/server

npm install

npm start

```



\- Task 1 runs at http://localhost:3000

\- Task 2 runs at http://localhost:4000
